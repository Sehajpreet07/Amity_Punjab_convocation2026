# Amity Punjab Convocation 2026 – Seat Finder

Enter your enrollment number to see your block, row, seat and entry gate for the convocation.

Live: https://sehajpreet07.github.io/Amity_Punjab_convocation2026/

## Updating the data

```
python3 tools/excel_to_students.py "Seating Plan.xlsx"
```

Event details (date, venue, timings, hall layout) are in `js/config.js`.
